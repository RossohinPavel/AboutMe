# RULES

Rules define constraints and conventions that must be followed while working in the repository.
Before starting any task, identify the applicable rules from their stated conditions and read the corresponding files.

## COMMON

- `.ai/rules/common/always-do-only-what-is-requested.md` Apply to every user request
- `.ai/rules/common/code-comments.md` Apply when maintaining comments for newly written or modified code in any programming language
- `.ai/rules/common/maximum-three-level-nesting.md` Apply when writing, modifying, refactoring, or reviewing code in any programming language

## JAVASCRIPT

- `.ai/rules/javascript/no-new-blank-lines-inside-blocks.md` Apply when writing or modifying JavaScript or TypeScript code

## REACT

- `.ai/rules/react/component-props.md` Load when writing, modifying, or reviewing React function components that receive props
- `.ai/rules/react/function-component-conventions.md` Load when working on any task in a React application project

## TYPESCRIPT

- `.ai/rules/typescript/avoid-any.md` Apply when writing or modifying TypeScript code
- `.ai/rules/typescript/explicit-void-for-floating-promises.md` Apply when writing or modifying TypeScript code that calls asynchronous functions
- `.ai/rules/typescript/prefer-type-inference.md` Apply when writing or reviewing TypeScript code

# SKILLS

Skills provide instructions and workflows for solving recurring repository tasks.
Load a skill when the task matches its stated usage condition.

## COMMON

- `.ai/skills/common/manage-project-version.md` Load when the user explicitly requests a push to a remote repository for a project that uses semantic versioning
- `.ai/skills/common/manage-readme.md` Load when the user explicitly requests any interaction with README.md
