# AboutMe

Простой сайт-визитка (лендинг) с информацией обо мне, моих навыках и проектах.

Основная цель проекта — структурирование портфолио, практика работы с современным фронтенд-стеком и настройка автоматического деплоя.

🔗 **Живая демо-версия:** [Ссылка на сайт](https://rossohinpavel.github.io/AboutMe/)

---

## Ключевые особенности

- **Интеграция с GitHub API:** Данные о репозиториях и активности подтягиваются динамически в реальном времени.
- **Современный стек:** Строгая типизация и компонентный подход.
- **Быстрая сборка:** Использование современных менеджеров пакетов для оптимизации работы.

---

## 🛠 Технологический стек

- **Основной фреймворк:** React
- **Язык программирования:** TypeScript
- **Менеджер пакетов:** pnpm

---

## 💻 Локальный запуск

Для запуска проекта на своем компьютере вам понадобятся установленные [Node.js](https://nodejs.org) и [pnpm](https://pnpm.io).

1. **Клонируйте репозиторий:**

2. **Перейдите в папку проекта:**
   ```bash
   cd AboutMe
   ```

3. **Установите зависимости:**
   ```bash
   pnpm install
   ```

4. **Запустите сервер для разработки:**
   ```bash
   pnpm dev
   ```

---

## ⚙️ Кастомизация

Проект легко адаптировать под себя.

Чтобы указать свои данные:
1. Откройте конфигурационный файл `./src/config/index.ts`.
2. Измените публичную ссылку на свои.
3. Для разработки будет удобно подготовить мог-файл. Поместите данные в `./mock/user.json`.
