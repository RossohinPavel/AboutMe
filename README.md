# AboutMe

Персональный сайт-визитка с краткой информацией обо мне, моих навыках и избранных проектах. Данные профиля и репозиториев загружаются через GitHub API.

🔗 [Открыть сайт](https://rossohinpavel.github.io/AboutMe/)

## Технологический стек

- React 19
- TypeScript 5
- Vite 8
- Sass и CSS Modules
- TanStack Query с сохранением кеша в `localStorage`
- Valibot для проверки данных GitHub API
- pnpm
- GitHub Pages

## Требования

- Node.js 24 LTS
- pnpm 11.22.0
- доступ к интернету для загрузки публичных данных из GitHub API

Токен GitHub и переменные окружения не требуются.

## Создание своей визитки

1. Сделайте форк репозитория и клонируйте его:

   ```bash
   git clone https://github.com/<ваш-пользователь>/AboutMe.git
   cd AboutMe
   pnpm install
   ```

2. Заполните своими данными файл [`src/user/manifest.ts`](src/user/manifest.ts):

   - имя, специализацию, местоположение и описание;
   - ссылки на резюме и контакты;
   - адрес профиля GitHub;
   - адрес будущей страницы в `github.appPage`;
   - список избранных репозиториев в `github.favorites`.

3. Замените файл `public/photo.jpeg` своей фотографией. Если имя файла отличается, обновите поле `image` в манифесте.

4. Проверьте визитку локально:

   ```bash
   pnpm dev
   ```

5. Опубликуйте production-сборку:

   ```bash
   pnpm deploy
   ```

   Команда соберёт проект и отправит содержимое каталога `dist` в ветку `gh-pages`. В настройках репозитория GitHub Pages выберите публикацию из корня этой ветки.
